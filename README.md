# Telecom-BSS-API-Testing
## Project Overview
This is a personal hands-on QA project focused on testing simulated Telecom  Business Support Systems (BSS) APIs. The goal is to practise API testing workflows commonly associated with telecom customers, product catalogues, order, charging, and payments.
## Objectives
Practise API testing using Postman.
Validate HTTP status codes and response bodies.
Learn positive and negative API test scenarios.
Practise SQL queries using a separate SQLite test database.
Document test cases, defects, and results.
Build practical knowledge of telecom BSS workflows.
## Tools
Postman-API requests and response validation
SQLite and DBeaver - SQL practice and test- data validation
GitHub - Project documentation and version control
Jira - Test and defect tracking practice

##Planned Test Scenarios
Successful authentication

Error response and negative testing
## Important Note 
This is an independent learning project using a simulated telecom API. It is not testing a live telecom operator's production systems and does not represent professional project experience in a telecom BSS environment.
## Security
Access tokens, client secrets, passwords, and other sensitive credentials will not be committed to this repository.
